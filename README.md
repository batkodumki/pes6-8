# Експертна система налаштування температури води

Програмний застосунок для виконання лабораторних робіт №6, 7, 8 з дисципліни «Проєктування експертних систем та систем підтримки прийняття рішень».

## Опис

Експертна система керує налаштуванням температури води в душі на основі продукційного представлення знань.

**Мета:** Отримати теплу воду (досягти стану f7 = true).

## Реалізовані лабораторні роботи

### ЛР6 - Розробка експертної системи
- База знань з 4 продукційних правил
- Робоча пам'ять з 8 фактами (f1-f8)
- Механізм логічного виводу (продукційний вирішувач)
- Інтерфейс для задання початкових значень фактів
- Покроковий протокол роботи алгоритму

### ЛР7 - Розробка підсистеми довіри
- Процедури виводу пояснень для користувача
- Людські пояснення кожного кроку алгоритму
- Функція друку результатів

### ЛР8 - Удосконалення інтерфейсу користувача
- Структурований інтерфейс з 5 основними блоками
- Кольорове виділення стану фактів (зелений/червоний)
- Зручні кнопки керування
- Приємне CSS-оформлення

## Як запустити

1. Переконайтеся, що всі три файли (`index.html`, `style.css`, `script.js`) знаходяться в одній папці
2. Відкрийте файл `index.html` у веб-браузері (Chrome, Firefox, Safari, Edge)
3. Використовуйте інтерфейс для:
   - Задання початкових значень фактів (чекбокси та поле для f8)
   - Запуску алгоритму (кнопка "Запустити алгоритм")
   - Перегляду протоколу роботи та пояснень
   - Очищення протоколу або скидання до початкових значень
   - Друку результатів

## Факти

- **f1** – вентиль гарячої води відкритий
- **f2** – вентиль холодної води відкритий
- **f3** – вентиль гарячої води повністю відкритий
- **f4** – вентиль холодної води повністю відкритий
- **f5** – вода гаряча
- **f6** – вода холодна
- **f7** – вода тепла (мета)
- **f8** – крок відкриття вентиля (число)

## Продукційні правила

1. Якщо вода гаряча і вентиль гарячої води відкритий → відкрити вентиль холодної води
2. Якщо вода холодна і вентиль холодної води відкритий → відкрити вентиль гарячої води
3. Якщо обидва вентилі відкриті, вода гаряча, і вентиль гарячої води повністю відкритий → закрити вентиль гарячої води
4. Якщо обидва вентилі відкриті, вода холодна, і вентиль холодної води повністю відкритий → закрити вентиль холодної води
